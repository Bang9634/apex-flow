위 관측은 짧은 연결 검사이며 전략 성과, 장시간 안정성, 실제 체결 정확도 또는
거래소 주문 필터 통과를 검증하지 않는다. Python 3.12에서의 별도 실행은 아직 검증하지 않았다.
검사 데이터베이스는 `/tmp/apex-flow-*-smoke.sqlite3`에 생성했고 저장소에 포함하지 않았다.

환경 특이 사항: 초기 샌드박스 DNS 제한을 네트워크 허용 실행으로 해결했다.
해당 실행 환경의 숨김 파일 속성 때문에 Python 3.14에서 editable `.pth`가
무시되어 명시적 `PYTHONPATH=src`로 실행했다. README에 우회 방법을 기재했다.
